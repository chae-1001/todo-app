  2. 스토리지 헬퍼 — lines 99–100

  function saveTheme(t) { localStorage.setItem(THEME_KEY, t); }
  'theme' 키로 localStorage에서 읽고 씁니다. 저장값이 없으면 기본값 'light'를
  반환합니다.

  ---
  3. applyTheme() — lines 245–248
  function applyTheme() {
    document.body.classList.toggle('dark', isDark);
    themeIcon.textContent = isDark ? '☀️' : '🌙';
  }
  isDark 값에 따라 <body>에 .dark 클래스를 붙이거나 떼고, 토글 버튼의 아이콘을
  교체합니다. CSS는 body.dark { ... } 선택자로 모든 색상 변수를 일괄 덮어씁니다.

  ---
  4. toggleTheme() — lines 250–255
  function toggleTheme() {
    isDark = !isDark;
    applyTheme();
    saveTheme(isDark ? 'dark' : 'light');
    showToast(isDark ? '다크 모드로 전환됐습니다' : '라이트 모드로 
  전환됐습니다');
  }
  isDark를 반전시킨 뒤 applyTheme()으로 DOM에 반영하고, saveTheme()으로
  localStorage에 저장하고, 토스트로 사용자에게 피드백을 줍니다.
